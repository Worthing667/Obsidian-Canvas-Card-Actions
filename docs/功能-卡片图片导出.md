# 功能：卡片图片导出

卡片图片导出用于把单张文本卡片或当前选中的多张文本卡片保存为一张 PNG，不修改原 Canvas。

## 入口

- 右键单张文本卡片：`将卡片导出为图片`
- 多选卡片后的选区菜单：`将选区导出为图片`
- 命令面板：`将选中卡片导出为图片`

当前版本不在选区浮动工具栏增加按钮。

## 单张导出

单张导出保留卡片当前主题、颜色、文本排版和 24 px 外边距。输出使用 2 倍像素比例，文件保存在当前 `.canvas` 文件所在目录，名称格式为：

```text
画布名-card-YYYYMMDD-HHmmss.png
```

若目标文件名已存在，会自动追加 `-1`、`-2`，不会覆盖已有文件。

## 多张 / 区域导出

多选时，插件把当前选区内的文本卡片作为一个区域导出：

- 保留卡片在 Canvas 中的相对位置和尺寸
- 只包含两个端点都在导出选区内的连线
- 选区中的文件卡片、链接卡片和 Group 不进入图片
- 输出文件名包含文本卡片数量，例如 `画布名-selection-3-YYYYMMDD-HHmmss.png`

导出范围以文本卡片的外接矩形为基础，并在四周增加 24 px 留白。

## 清晰度与尺寸限制

默认按 2 倍像素比例输出。为避免超大 Canvas 选区耗尽内存，插件同时限制：

- PNG 最长边不超过 12000 像素
- PNG 总像素不超过 6400 万

当 2 倍输出超过任一限制时，会等比例降低实际像素比例，不改变卡片布局。

## 内容边界

当前版本聚焦文本卡片。文本卡片中的图片、音视频、网页框架和其他嵌入媒体不会进入导出图片；导出器也跳过字体下载。这样可以在不主动获取外部资源的前提下完成卡片文字和内部连线的导出。

导出依赖 Obsidian Canvas 当前运行时提供已渲染的卡片和连线 DOM。若运行时能力不可用、卡片仍在编辑、卡片尚未渲染完成或当前文件不是 `.canvas`，插件会停止导出并提示原因。

## 状态恢复

渲染时会临时清空选中外观并启用 Canvas 截图状态。无论导出成功还是失败，插件都会恢复：

- 原选区
- 原截图状态
- 临时导出样式

PNG 通过 `Vault.createBinary` 写入当前仓库，不写入仓库外部路径。
