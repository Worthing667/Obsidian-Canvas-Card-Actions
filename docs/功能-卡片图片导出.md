# 功能：工作台预览图片导出

图片导出是 Loom 工作台 `预览` 面板的输出动作：它把当前预览文本保存为 PNG，不修改原 Canvas。

## 使用方式

1. 在 Canvas 中选中一张或多张文本卡片，打开 `预览卡片组`
2. 在工作台中按需要调整排序方式、手动顺序和分隔符
3. 切换到 `预览` 面板，确认预览结果
4. 点击输出操作中的 `导出图片`

导出前会立即刷新预览，因此导出的内容与当前工作台状态一致，不会把“正在生成预览”一类的临时文字写入图片。

## 导出内容

图片以工作台的最终预览为准：

- 使用当前卡片顺序，包括手动拖拽后的顺序
- 使用当前分隔符和预览文本
- 使用工作台预览区域的主题、背景和文本排版
- 不保留 Canvas 中卡片的空间位置、尺寸或连线

这使图片导出与复制、新建卡片、新建文稿同属预览结果的输出方式，而不是另一套 Canvas 截图逻辑。

## 输出文件

PNG 保存在当前 `.canvas` 文件所在目录，名称格式为：

```text
画布名-preview-卡片数-YYYYMMDD-HHmmss.png
```

单张卡片会省略卡片数，例如：

```text
画布名-preview-YYYYMMDD-HHmmss.png
```

若目标文件名已存在，会自动追加 `-1`、`-2`，不会覆盖已有文件。PNG 通过 `Vault.createBinary` 写入当前仓库，不写入仓库外部路径。

## 内容边界

导出器以 2 倍像素比例渲染工作台预览。字体嵌入被关闭，图片、音视频、网页框架及其他嵌入媒体会被跳过，因此导出不会主动获取外部资源。

如果无法定位源 `.canvas` 文件或图片渲染失败，插件会保留工作台内容并显示失败提示；开发者控制台会记录具体错误。
