# 功能：Canvas 缩放控件

Canvas Loom 可以在 Obsidian Canvas 左下角显示一个轻量缩放控件，用于在不离开画布的情况下快速调整当前 Canvas 的缩放倍率。

## 用户交互

控件包含三类入口：

- 滑块：用于快速拖动缩放倍率。
- 百分比输入框：用于手动输入精确倍率。
- 加号 / 减号按钮：按固定步长微调倍率。

缩放范围为 `10%–200%`。其中 `100%` 表示 Obsidian Canvas 的默认显示倍率，`200%` 表示当前确认的原生最大倍率，`10%` 表示当前确认的原生最小倍率。

控件不提供预设倍率按钮，避免按钮状态和滑块 / 输入框同时竞争缩放来源。

## 设置项

设置项为 `在画布内显示缩放控件` / `Show zoom control on canvas`。

关闭后不会修改 Canvas 文件，也不会改变 Obsidian 原生缩放行为；只移除 Canvas Loom 注入的缩放 UI。

## 实现边界

缩放控件只调用当前 Canvas 运行时对象的视口方法，不写入 `.canvas` 文件内容。

Obsidian Canvas 内部的缩放字段不是用户看到的倍率：

- `scale` 是实际倍率，例如 `1` 表示 `100%`，`2` 表示 `200%`。
- `zoom` / `tZoom` 是内部对数值，语义为 `log2(scale)`。

因此 Canvas Loom 的 UI 层始终使用真实倍率和百分比；调用 Obsidian `setViewport(tx, ty, tZoom)` 前，会把真实倍率转换为 `Math.log2(scale)`。读取运行时状态时，优先使用 `scale`；只有缺失时才把 `zoom` / `tZoom` 转换回真实倍率。

这个转换是必要的。否则把 `190%` 当成 `1.9` 直接传给 `tZoom`，Obsidian 会按 `2 ** 1.9` 理解为约 `373%`，随后被内部最大值钳回 `200%`，表现为缩放后又自动跳回。

## 验收要点

- 从 `200%` 点击减号后，应稳定停留在 `190%`。
- 从 `190%` 继续下调，不应自动跳回 `200%`。
- 滑块拖动到任意合法值后，画面缩放和输入框显示应一致。
- 手动输入小于 `10%` 或大于 `200%` 的值时，会钳制到边界。
- 手动缩放 Canvas 后，控件显示应同步到当前实际倍率。
