# 功能：卡片内容复制与排序

## 用途

处理单张或多张文本卡片的内容输出。多卡片场景分为“直接完成”和“进入工作台”两条路径。

相关代码：

- `src/presentation/commands/CopyCommands.ts`
- `src/presentation/commands/QuickActionCommands.ts`
- `src/presentation/commands/ColorGroupCommands.ts`
- `src/services/ContentService.ts`
- `src/services/MergeService.ts`
- `src/services/PreviewWorkbenchService.ts`
- `src/services/ColorGroupService.ts`
- `src/presentation/views/MergeWorkbenchView.ts`

## 单张卡片

- 右键单张文本卡片
- 使用 `复制卡片内容`
- 直接复制纯文本，不涉及排序

## 多张卡片的快速操作

### `一键复制`

- 读取当前选区
- 按设置中的 `一键排序方式` 排序
- 直接复制到剪贴板

### `一键拼合`

- 读取当前选区
- 按设置中的 `一键排序方式` 排序
- 在当前 Canvas 新建一张合并卡片
- 根据设置中的 `拼合后处理方式` 决定是否删除原卡片

拼合为新卡片时，新卡片会使用当前排序后第一张卡片作为锚点，继承它的位置和尺寸。选择“新建并删除原卡片”时，相关边也会一起移除。

默认排序方式支持：

- `按位置顺序`
- `按标记顺序`

按标记顺序输出时，文本格式为：

```text
[标记] 内容
```

## Loom工作台与卡片组预览

### 入口

- 多选文本卡片
- 选择 `预览卡片组`

### 能力

- 切换排序模式
- 查看当前顺序
- 在当前排序基础上拖拽微调顺序
- 预览最终文本
- 输出到剪贴板、Canvas 新卡片或 Markdown 文稿

### 排序模式

- `位置`：默认按画布位置排序，可继续拖拽调整顺序
- `标记`：先按数字标记排序，相同标记或无标记卡片继续按位置排序，也可继续拖拽调整顺序

一旦拖拽调整过顺序，工作台会显示为“位置 + 手动调整”或“标记 + 手动调整”。后续 `复制`、`拼合为新卡片`、`新建文稿` 都使用拖拽后的当前顺序。

### 预览行为

- 预览页直接显示最终文本
- 预览内容有 `200ms` 防抖
- 输出按钮与预览区使用同一份当前顺序结果

### 侧边栏行为

- 工作台使用 Obsidian 标准 `ItemView`
- 工作台 leaf 会跟随 Obsidian 布局保留；重开后即使还没有渲染卡片，也会显示基础工作台页面
- 重复执行 `预览卡片组` 会复用已有工作台；同一 Canvas 来源会追加并刷新卡片快照，不会无限新建侧边栏页面
- 如果历史原因已经存在多个工作台 leaf，打开时会保留一个并清理多余实例
- 插件卸载时不会主动移除工作台 leaf，重新启用插件后可继续复用该页面

### 源 Canvas 恢复

工作台保存了载入卡片组时的源 `.canvas` 文件路径。因此从工作台执行 `拼合为新卡片` 时，不要求原 Canvas 仍然是当前激活页面：

1. 优先复用已经打开的源 Canvas leaf
2. 如果没有找到，则尝试在后台打开源 `.canvas`
3. 拿到 Canvas 运行时后再写入合并卡片

找不到源文件或无法恢复 Canvas 运行时时，会提示失败，不会把新卡片写到错误的画布。

## 同色卡片分组

单张或多张文本卡片右键时，若选区内存在文本卡片，会出现 `选中同色卡片`：

- 单卡片场景：以当前卡片颜色为基准选中同色文本卡片
- 多卡片场景：以当前选区颜色为基准扩展选中同色文本卡片
- 命令面板还提供 `预览同色卡片分组`，会把同色分组结果送入同一个 Loom工作台

同色分组只改变选区或工作台快照，不会修改 `.canvas` 数据。

## 设置项

- `设置卡片排序优先级`
  只影响位置排序优先按纵向还是横向。
- `一键排序方式`
  影响 `一键复制` 和 `一键拼合` 的默认排序模式。
  当选择 `按标记顺序` 时，有标记卡片优先，无标记卡片排在最后。
- `拼合后处理方式`
  影响 `一键拼合`、旧的合并为新卡片命令，以及工作台里的 `拼合为新卡片`。

## 适合使用工作台的场景

- 需要先检查合并结果
- 需要从自动排序继续手动调整
- 需要导出 Markdown 文稿
- 原 Canvas 可能已经切走，但仍希望把结果写回原始画布
