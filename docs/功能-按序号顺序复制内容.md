# 功能：按序号顺序复制内容

## 功能概述

“按序号顺序”统一处理正文中的第一行序号和独立卡片标记，适合整理步骤、章节和有层级的内容。卡片标记仍独立保存在 Canvas 数据中，不会写入或修改正文。

## 排序规则

每张卡片按以下优先级取得序号：

1. 第一行开头的数字序号
2. 卡片的独立数字标记
3. 没有序号时按画布位置排序并排在有序号卡片之后

支持的第一行形式包括：

```text
# 1. 标题
## 2.1 标题
3、标题
4) 标题
```

层级序号按数字段比较：

```text
1 < 2 < 2.1 < 2.10 < 10
```

第一行序号与卡片标记同时存在时，使用第一行序号。相同序号之间继续复用当前的位置排序规则，方向受 `设置卡片排序优先级` 影响。

## 输出规则

序号只用于排序。复制、拼合为新卡片和新建文稿都会保留原始正文，不自动添加 `[标记]` 前缀。

## 使用场景

- 卡片正文已经带章节号时直接排序
- 正文不适合修改时使用独立标记
- 先批量添加标记，再在工作台中手动微调
- 混合处理有标题序号、仅有标记和无序号的卡片
