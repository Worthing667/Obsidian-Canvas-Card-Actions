# 功能：拆分 Canvas 卡片

## 用途

将单张文本卡片按规则拆成多张卡片，适合整理长笔记、会议记录和分层提纲。

## 入口

- 单张文本卡片右键
- 选择 `拆分卡片...`
- 在弹出的选择器中执行具体拆分方式

相关代码：

- `src/main.ts`
- `src/presentation/modals/SplitCardModal.ts`
- `src/services/CardService.ts`

## 支持的拆分方式

### 按分隔符拆分

- 使用设置中的 `canvasCardDelimiter`
- 清理空白段落后再拆分
- 第一段保留在原卡片
- 其余段落创建为新卡片

### 按空行拆分

- 直接在拆分弹窗中选择，不依赖分隔符设置
- 识别段落之间的一行或多行空行，包含只由空格或 Tab 组成的空白行
- 每个非空段落拆成一张卡片
- 连续空行不会产生空卡片
- 如果某个独立段落等于当前设置的分隔符，则会跳过该段落，避免把分隔符生成一张卡片

### 按标题层级拆分

- 识别 `#` 到 `######`
- 只把选定层级的标题当作新卡片起点
- 更深层标题保留在所属父级内容中
- 标题前存在非空正文时，会先拆成独立正文卡片，再从标题开始拆出标题卡片
- 如果卡片从目标层级标题开始，则第一张拆分结果仍从该标题开始

## 选择器行为

- `按分隔符拆分` 始终显示
- 检测到分隔符时可点击，并显示预计拆分数量
- 未检测到分隔符时显示禁用提示
- `按空行拆分` 始终显示
- 检测到可拆分空行时可点击，并显示预计拆分数量
- 未检测到空行时显示禁用提示
- `按标题拆分` 能力始终显示
- 没有可用标题层级时显示禁用提示，不隐藏功能

## 新卡片规则

- 原卡片更新为第一段内容
- 新卡片继承原卡片宽高
- 拆分结果每行最多排列数量由设置项 `splitCardsPerRow` 控制，默认 5 张，包含原卡片
- 换行时按卡片高度加固定间距下移，避免上下两行重叠
- 原卡片更新和新卡片追加在一次 Canvas 数据写入中完成
- 创建完成后调用保存逻辑写回 `.canvas`

## 限制与反馈

- 拆分结果少于 2 张卡片时不会执行
- 非文本卡片不会显示此入口
- 分隔符由插件设置控制，默认值为 `'---'`
- 每行卡片数可在设置页调整，支持 `1-20` 的整数
