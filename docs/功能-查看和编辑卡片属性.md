# 功能：查看和编辑卡片属性

## 用途

通过统一入口管理单张或多张文本卡片的尺寸、位置、标记和排列。

相关代码：

- `src/presentation/commands/PropertiesCommands.ts`
- `src/presentation/modals/SingleCardPropertiesModal.ts`
- `src/presentation/modals/CardPropertiesModal.ts`
- `src/services/CardService.ts`

## 入口

- 单张文本卡片右键：`管理卡片属性`
- 多选文本卡片菜单：`管理卡片属性`
- 命令面板：`复制选中卡片的尺寸`

插件会根据当前选区数量自动打开对应的属性查看器。

## 单卡片模式

- 查看尺寸、位置、标记和内容预览
- 单独调整宽度和高度
- 复制尺寸、位置或完整属性信息
- 尺寸输入范围为 `50–2000 px`

## 多卡片模式

- 查看选区数量和尺寸范围
- 浏览每张卡片的基础属性
- 统一调整宽高
- 只统一宽度或只统一高度
- 可锁定宽高比，按平均宽高比推导另一维度
- 复制统计或尺寸信息

## 一键排列

多卡片属性管理器内提供 `一键排列` 区域：

- 支持 `水平（左→右）` 和 `垂直（上→下）`
- 支持设置卡片间距，范围为 `0–500 px`
- 支持按位置顺序决定排列次序：
  - `yx`：从上到下，再从左到右
  - `xy`：从左到右，再从上到下
- 排列时第一张卡片位置保持不变，其余卡片按方向和间距依次移动

这个能力只调整选中文本卡片的 `x` / `y`，不会修改卡片内容、尺寸、颜色、标记或边。

## 写入行为

- 批量尺寸调整会读取当前 Canvas 数据，修改目标文本节点后写回
- 一键排列同样在一次 Canvas 数据写入中完成
- 成功后调用保存逻辑写回 `.canvas`
- 操作失败时会保留原始数据，并在界面中提示失败原因

## 实现约束

属性管理弹窗当前遵守以下约束：

- 界面结构通过 `createEl` / `createDiv` 构建
- 不直接写 `innerHTML`
- 样式统一走插件根目录 `styles.css`

这样做的原因是：

- 这样才符合 Obsidian 官方规范
- 也能避免弹窗结构、主题适配和后续维护变得分散

## 适用场景

- 检查某张卡片的实际尺寸和位置
- 批量统一卡片视觉规格
- 复制尺寸用于手动对齐其他卡片
- 把散乱的选中卡片按水平或垂直方向快速排成一列
