## Canvas Loom 1.8.4

- 新增：按标题拆分时，会把第一个标题前的正文保留为独立卡片。
- Added: When splitting by headings, content before the first heading is now kept as its own card.

- 新增：设置页增加联系和支持开发入口。
- Added: The settings page now includes contact and support options.

- 优化：整理间距交互更清晰，适合处理横向或纵向排列的卡片。
- Improved: Spacing cleanup is clearer for cards arranged horizontally or vertically.

- 优化：工作台查找结果不再额外高亮，预览更简洁。
- Improved: Workbench search results no longer add extra highlighting, keeping previews cleaner.

- 修复：提升部分 Canvas 缩放和查找替换场景下的兼容性。
- Fixed: Improved compatibility in some Canvas zoom and find/replace cases.

- 说明：发布流程现在使用人工确认的中英双语发布说明。
- Note: Releases now use manually confirmed bilingual release notes.
