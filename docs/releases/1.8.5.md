## Canvas Loom 1.8.5

- 优化：设置页按功能分区整理（基础设置、卡片处理、画布显示、性能、支持），查找更直观。
- Improved: Settings page is now organized into sections (Basic, Card Processing, Canvas Display, Performance, Support) for easier navigation.

- 兼容性：对仍在使用旧版 Obsidian 设置界面的用户增加兼容性提醒与回退渲染支持。
- Compatibility: Added compatibility notice and fallback rendering for users still on the legacy settings view of older Obsidian versions.
