# 功能：卡片标记

## 用途

为 Canvas 卡片添加数字序号标记，用于排序、编号和后续内容整理。

相关代码：

- `src/presentation/commands/BadgeCommands.ts`
- `src/presentation/modals/BadgeModal.ts`
- `src/services/BadgeService.ts`
- `src/services/BadgeRenderScheduler.ts`
- `src/presentation/styles/BadgeStyles.ts`

## 使用方式

1. 右键文本卡片
2. 选择 `编辑标记`
3. 输入数字序号，例如 `1`、`2.1`、`10.3.2`
4. 保存后立即显示

移除标记时，可以清空输入内容或使用移除操作。

## 批量标记

多选文本卡片后，选区浮动工具栏会显示标记按钮。点击后打开 `序号工具`：

- `批量编号...`：输入起始标记，按画布位置顺序连续编号
- `移除 N 个标记`：直接移除选区中实际存在的标记

只选中一张文本卡片时，同一入口会改为显示 `设置序号...` 和 `移除标记`，并打开单卡片序号弹窗。

右键菜单中的 `编辑序号` 和命令面板入口会打开同一个浮动工具栏面板。右键菜单目前作为过渡入口保留，后续可以在用户熟悉新入口后移除。

批量编号规则：

- 起始标记 `1` 会生成 `1`、`2`、`3`
- 起始标记 `2.1` 会生成 `2.1`、`2.2`、`2.3`
- 当选区同时包含有标记和无标记卡片时，默认只给无标记卡片编号，也可以切换为重新编号全部卡片
- 当选区全部有标记或全部无标记时，默认处理全部卡片
- 提交前会显示序号与卡片第一行的对应预览

批量操作只写入实际发生变化的节点；没有变化时不会重复保存 Canvas。

## 输入规则

- 仅支持数字序号
- 正则规则：`/^\d+(\.\d+)*$/`
- 允许层级编号，例如 `1.2`、`2.10.3`
- 非法输入会在弹窗内直接拦截，不能提交

## 存储与显示

- 标记数据直接写入 `.canvas` 节点的 `badge` 字段
- 关闭或重新打开后仍会保留
- 分享 `.canvas` 文件时会一起带出
- 显示为卡片右上角药丸标记
- 标记样式统一定义在插件的 `styles.css` 中，并使用 Obsidian 主题变量跟随当前主题

这样处理的原因是：

- 标记显示逻辑和样式来源更稳定，也更容易维护

## 加载与性能

打开 Canvas 或切换布局后，插件会把 `.canvas` 数据中的 `badge` 字段同步到对应节点 DOM 上的 `data-badge`。

当前加载策略：

- 同一 Canvas 文件的重复加载请求会按 `标记更新防抖时间` 合并
- 大 Canvas 会按批次分帧写入 DOM，避免一次性处理过多节点
- 同一次调度中已应用过且内容没有变化的标记会跳过重复写入
- 关闭标记功能或卸载插件时，会取消待执行的定时器和动画帧，并清理 DOM 上已有的 `data-badge`

大 Canvas 的判断使用设置项 `大 Canvas 阈值`，默认 `80` 个节点。

## 设置项

- `启用标记功能`
  控制标记显示开关。
- `大 Canvas 阈值`
  控制何时使用更保守的分帧更新策略。
- `标记更新防抖时间`
  控制标记 DOM 更新延迟，默认 `150ms`。

当关闭时：

- 停止给当前画布节点补显示用的 `data-badge`
- 跳过标记加载
- 清理 DOM 上已有的 `data-badge`

当打开时：

- 重新把 `.canvas` 中已有标记加载到当前画布
