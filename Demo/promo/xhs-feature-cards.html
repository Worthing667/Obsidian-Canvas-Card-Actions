核心工作流
拆分与拼合

长文拆成卡片，
卡片再拼回文稿

Canvas Loom 的核心是这组互逆动作：一张长文卡片拆成多张结构卡片；散落的卡片组也可以按顺序重新拼合成完整文本。

整理标记、移动、排序，保留画布思考痕迹
拼合重新输出为剪贴板、Markdown 文稿或新卡片

CLCanvas Loom
规则说明
拆分方式怎么判定

规则先说清楚，
输出才稳定

拆分不是随便切文本。Canvas Loom 会根据当前卡片内容自动计算每种方式会拆出多少张卡片，让你先判断再执行。

长卡片拆分规则
按分隔符适合已经用固定符号分段的会议纪要、访谈记录。
按空行适合自然段落清楚的笔记和摘录。
按二级标题适合 Markdown 提纲，二级标题成为新卡片起点。
按三级标题更细层级也可拆分，深层标题保留在所属卡片里。
保留结构拆分后仍是 Canvas 卡片，可以继续移动和连线。
自动计算每种规则都会先显示预计拆分张数。
限制单行数量拆分后自动排布，避免一排卡片无限横向铺开。
把“怎么拆”提前算清楚，执行前就知道结果规模 03 / 09

标记功能
标记方式与用途

画布位置乱了，
输出顺序也不乱

给卡片加上 1、2.1、10.3.2 这类数字层级标记。它既是画布上的顺序提示，也是工作台拼合时的稳定排序依据。

批量添加和移除标记
画布上的标记效果
单卡片标记给关键节点补上明确顺序。
批量标记一次给多张卡片连续编号，也能统一移除。
按标记输出位置被挪动后，仍按编号拼合内容。
写作大纲、课程笔记、项目材料，都能先编号再输出 04 / 09

预览卡片组

先看拼合结果，
再决定怎么输出

工作台常驻侧栏。你可以把卡片组放进来，手动拖动排序，预览拼合后的内容，再一键复制、新建卡片、新建文稿或清空列表。

Loom 工作台
拖动排序卡片列表可以手动调整，当前顺序直接进入预览。
预览拼合先看完整文本，再决定是否输出。
一键复制把拼合后的内容放进系统剪贴板。
新建卡片在当前 Canvas 中生成一张拼合后的新卡片。
新建文稿输出为 Markdown 文稿，适合归档和继续写作。
一键清空整理完一组内容后，马上切到下一组。
不是只执行一次命令，而是把卡片组整理成一个流程 05 / 09

排序解释
两种排序

按画布位置，
也能按标记顺序

同一组卡片，可以用不同逻辑进入工作台。位置排序跟随画布坐标，标记排序跟随编号，状态栏会直接说明当前排序规则。

原始卡片组

按标记排序状态栏
原始状态先从同一组 Canvas 卡片出发。
位置排序从上到下、从左至右，适合规整画布。
标记排序按 1、2.1、3 等编号组织输出。
复杂画布里，排序规则比“看起来差不多”更可靠 06 / 09
